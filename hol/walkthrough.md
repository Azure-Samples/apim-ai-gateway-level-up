# Session Three — MCP & A2A from an APIM Perspective

Session Three was a **concept-focused** session. We covered the fundamentals of
the **Model Context Protocol (MCP)** and **Agent-to-Agent (A2A)** patterns, and
how **Azure API Management** fits in as the AI gateway for both.

There were **no hands-on activities** to follow in this session. The goal was to
understand the concepts and where APIM adds value — governance, security,
authentication (OAuth/OBO), and mediation — when exposing MCP servers and A2A
agents through the gateway.

The hands-on labs that build on these concepts are covered in **Session Four**.
